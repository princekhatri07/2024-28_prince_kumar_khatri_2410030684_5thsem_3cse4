## About the Internship

This repository documents the learning journey associated with the
**Google Cloud Generative AI Virtual Internship**.

The internship follows a structured eight-week curriculum covering
Generative AI fundamentals, responsible AI, prompt engineering,
multimodal techniques, modern model architectures, embeddings,
multimodal Retrieval-Augmented Generation (RAG), MLOps, and AI agents.

The supplied internship offer letter states that the program combines
structured learning with practical exposure and includes weekly
assessments, assignments or project documentation where required, and a
final assessment.

## Learning Objectives

The internship curriculum focuses on:

-   Understanding Generative AI and large language models (LLMs)
-   Learning the differences between Generative AI and traditional
    machine learning
-   Practising prompt engineering
-   Exploring multimodal AI and image-analysis techniques
-   Understanding responsible and ethical AI principles
-   Learning about diffusion models, attention mechanisms,
    encoder--decoder architectures, and transformers
-   Exploring embeddings and multimodal RAG with Gemini
-   Understanding MLOps practices using Vertex AI
-   Exploring business applications of Generative AI
-   Understanding AI applications and AI-agent workflows
